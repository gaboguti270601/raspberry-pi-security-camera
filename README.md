# Raspberry Pi Security Camera

Motion-detection security camera developed with **Python**, **OpenCV**, **PyQt5** and **Telegram Bot API**.

The application displays a live camera feed, detects motion by comparing consecutive frames, saves captures locally and sends Telegram notifications when significant movement is detected.

## Overview

This project was developed as part of the Telecommunications Engineering program at the University of Concepción.

The system integrates computer vision, graphical user interfaces and remote notifications in a single application.

The main functions are:

- Live camera visualization
- Motion detection
- Automatic Telegram alerts
- Automatic image capture
- Manual image capture
- Local storage of captured images
- Graphical interface built with PyQt5

## How It Works

The application continuously reads frames from the connected camera.

Each frame is converted to grayscale and compared with the previous frame using OpenCV.

The main motion-detection pipeline includes:

1. Frame acquisition
2. Grayscale conversion
3. Gaussian blur
4. Absolute difference between consecutive frames
5. Binary thresholding
6. Image dilation
7. Contour detection
8. Contour-area filtering
9. Motion alert generation

Small contours are ignored to reduce false detections caused by camera noise or minor lighting changes.

When significant movement is detected, the system can save the frame and send it through Telegram.

## Motion Detection

Motion is detected by calculating the absolute difference between the current frame and the previous frame.

The resulting image is converted into a binary mask.

Contours are extracted from this mask and filtered according to their area.

Only contours larger than the configured minimum area are considered significant movement.

```python
MIN_CONTOUR_AREA = 1000
```

This value can be adjusted depending on the environment and desired sensitivity.

## Telegram Notifications

When motion is detected, the application:

- Captures the current frame
- Saves the image locally
- Sends the image through a Telegram bot
- Sends a message containing the detection date and time

To prevent repeated notifications, the application uses a minimum interval between alerts.

```python
ALERT_INTERVAL = 60_000
```

This corresponds to approximately one alert per minute.

## Installation

Clone the repository:

```bash
git clone https://github.com/gaboguti270601/raspberry-pi-security-camera.git
cd raspberry-pi-security-camera
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Environment Configuration

The application uses environment variables for the Telegram bot credentials.

Create a `.env` file inside the directory where the main application is executed.

```env
BOT_TOKEN=your_telegram_bot_token
CHAT_ID=your_telegram_chat_id
```

The `.env` file is ignored by Git and should **not** be uploaded to the repository.

## Running the Application

Move into the source directory:

```bash
cd src
```

Run the application:

```bash
python Interfaz.py
```

The application will attempt to open the default camera connected to the system.

## Captured Images

The program automatically creates local folders for captured images.

```text
Capturas/
Envios/
```

`Capturas/` stores manually captured images.

`Envios/` stores images generated by automatic motion alerts.

These folders are excluded from the Git repository.
